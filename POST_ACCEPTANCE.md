# Post-acceptance release checklist

After double-anonymous review is over:

1. Add final author names, affiliations, ORCID IDs, and contact information where appropriate.
2. Add a `CITATION.cff` with the final bibliographic metadata.
3. Add an explicit license for original code and repository-authored materials; do not relicense third-party data.
4. Replace anonymous-review notes with normal repository documentation.
5. Add the final camera-ready paper.
6. Tag a versioned release.
7. Consider archiving the release in a DOI-bearing repository such as Zenodo.
8. If an ACM artifact-evaluation process is available, follow its required packaging instructions.
